## 競走馬の名前のきまり

JRAの競走馬の名前は、カタカナで2〜9文字。馬主が名前を決め、どんな意味かを添えて届け出る。いま登録されている馬と同じ名前や、G1を勝った馬などの名前は使えない。JRAの競走馬情報には、届け出た「馬名の意味」が載っている。

## 冠名（かんめい）

冠名は、同じ馬主の馬に共通して付ける言葉。「メイショウ」「サトノ」のように名前の頭に付けることが多い。今回の1,659頭のうち、馬名の意味に「冠名」と書かれている馬は572頭（34.5%）。冠名を付けた馬の持ち主（馬主）は、個人と法人を合わせて241。

### 頭数の多い冠名

意味が「冠名＋◯◯」の馬を馬主ごとに分け、名前の頭の共通部分を冠名として数えた（5頭以上）。

## 父や母の名前から連想した名前

「母名より連想」のように、意味に母の名前が出てくる馬は238頭、父の名前は139頭、母の父の名前は8頭。親の名前の一部を受け継いだり、親の名前から連想した言葉を付けたりする。

- **ダノンデサイル**（日本ダービーなど重賞4勝）：冠名+母名の一部
- **ミッキーヌチバナ**（重賞のアンタレスSを勝った）：冠名+母名
- **ホーエリート**（重賞のステイヤーズSを勝った）：賛歌、雅歌(独)。母名より連想
- **バステール**（重賞の弥生賞を勝った）：グアドループの都市名。母名より連想

## 使われている外国語

馬名の意味に「(仏)」「(伊)」や「ラテン語」のように言語名が書かれているものを数えた。英語の言葉には、ふつう言語名が書かれないので、この表にはほとんど出てこない。

## 名前の文字数

| 文字数 | 頭数 | 割合 |
|---|---|---|
| 2文字 | 3 | 0.2% |
| 3文字 | 22 | 1.3% |
| 4文字 | 73 | 4.4% |
| 5文字 | 150 | 9.0% |
| 6文字 | 237 | 14.3% |
| 7文字 | 375 | 22.6% |
| 8文字 | 403 | 24.3% |
| 9文字 | 396 | 23.9% |

上限の9文字の名前は396頭（23.9%）。いちばん多いのは8文字だった。

冠名を使っていない9文字の名前の例：クイーンズウォーク、シェイクユアハート、ヴァルツァーシャル、マスカレードボール、ゴーイントゥスカイ、サンダーストラック

2文字の名前と、その意味：

- **セオ**：男子名。父名からの連想
- **バム**：夜(ハングル)
- **ムイ**：妹(広東語)

> 対象は10月25日〜11月15日にJRAのレースを走った3歳以上の馬1,659頭で、JRAの競走馬情報を1頭ずつ確かめた。いま走っている馬だけを数えているので、引退した馬や2歳の馬は入っていない。
