# レースシミュレーション 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 各レースページに、AIの勝率で着順を決め脚質で道中を描くレースシミュレーション（演出）を付ける。

**Architecture:** `site/racesim.py` がレースごとのデータ（馬番・枠・印・勝率・脚質・コース）をJSONにしてページへ埋め込み、`site/racesim.js` がそれを読んでCanvasに描画する。JSはレースページでだけ読み込む。

**Tech Stack:** Python 3.12（既存の build.py）、素のJavaScript（Canvas 2D、Web Speech API）、テストは pytest と node:test。

**Spec:** `docs/superpowers/specs/2026-11-16-race-sim-design.md`

## Global Constraints
- 動画ファイルは作らない。外部ライブラリは増やさない（requirements.txt・CDNとも）
- 表示名は「レースシミュレーション（演出）」。勝率とセットで見せる
- ばんえい・障害レース・出走馬データの無いレースには出さない
- 1,000回集計はレースIDから決まる乱数（見るたびに同じ数字）
- 音声は初期状態でオフ
- 既存のダークモード（CSS変数 --bg/--fg/--line/--acc 等）に従う

## Review Focus
- 補正勝率が一部の馬にしか無い／合計が100にならない → 正規化して全頭に勝率がある
- 通過順データが無い馬（新馬・地方の初出走） → 脚質0.5で動き、エラーにならない
- 出走取消などで評価に無い馬 → シミュレーションに出さない
- 18頭立て・3,000m超（1周以上） → 重ならず描け、全頭がゴールする
- スマホ幅（360px）とダークモード → 読める大きさ・色で描かれる
