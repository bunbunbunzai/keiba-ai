# 全頭ログ オーナーズリーグ（β・非公開）

読者が仮想馬を1頭持ち、毎週「調教」と「実在馬の指名」をして、指名した馬の確定着順で月間ランキングを競うゲーム。

## 構成

| 部分 | 場所 | 備考 |
|---|---|---|
| ルール・検証 | `league/src/core.js` | 調教・出走・締切・取消・中止・訂正・上位3節・同点・賞品按分。Worker とテストで共用 |
| API | `league/src/index.js` | Cloudflare Workers `keiba-league` ＋ Durable Object（SQLite）。「全頭くんに質問」（`keiba-ask`）とは別の Worker・別のDB |
| 画面 | `site/league.py` | `/league/`（厩舎）`/league/race/`（今週の出走）`/league/ranking/`（月間ランキング）`/league/rules/`（規約）`/league/admin/`（管理） |
| 導線 | `site/column.py` | 全頭診断（重賞の自動記事）→ `/league/race/?site_race=<レースID>`（対象レースなら選択済みで開く） |
| テスト | `league/test/` | `league.test.mjs`（ルール12件）、`api.e2e.mjs`（HTTP通し）、`ui-walkthrough.cjs`（画面の通し・架空データ） |
| CI・配備 | `.github/workflows/league.yml` | push でテスト。手動実行で `deploy=yes` のときだけ配備 |

## ルールの要点（規約ページと同じ）

- 調教：1節1回、スピード／スタミナ／パワー。その月の回数がレベル。月替わりで0。
- 加点：対象レースの適性（芝短距離＝スピード、芝中長距離＝スタミナ、ダート＝パワー）と一致すれば 1レベル5%・最大10%。
- 着順ポイント：1〜5着 1000／600／400／250／150、6着以下0。賞金・オッズは使わない。
- 締切：節ごとに1つ。既定は対象レースのうち最初の発走時刻（JST）。管理者が明示も可。締切後は登録・変更・調教すべて不可。
- 公開範囲：締切前は自分の指名だけ。締切後に全員分を公開。同じ実在馬の複数指名は可。
- 取消・中止：締切後の取消・除外は0点、中止レースも0点。結果訂正はその節の得点を作り直すので二重にならない。
- 月間：4節のうち上位3節の合計。同点は同順位（1,1,3…）。称号は1〜3位（0点は対象外）。
- 賞品：優勝1,000円、2・3位各500円（Amazonギフトカード、月間総額2,000円）。同順位は「占める枠の賞品合計を人数で等分、1円未満切り捨て」。月ごとの設定＋全体のスイッチ＋管理者の承認で確定。購入・送付は手作業。
- 無料。課金・馬券購入・アフィリエイト申込みは参加条件にも優遇にもならない。ポイントは換金・譲渡不可。

## スイッチ（すべて既定OFF）

| スイッチ | 場所 | OFFのとき |
|---|---|---|
| `LEAGUE_PUBLIC` | `league/wrangler.toml` の vars ＋ 管理画面「一般公開」 | `PREVIEW_CODE` を知っている人と管理者だけが使える |
| `PRIZES_ALLOWED` | `league/wrangler.toml` の vars ＋ 管理画面「賞品を使う」 | 月を賞品付きにしても賞品は表示・計算されない（称号・トロフィーのみ） |
| `LEAGUE_URL` | GitHub の repository variable（Pages のビルド） | `/league/` の画面を作らない（いまの本番と同じ） |

## プレビューまでの手順（オーナー作業）

1. GitHub Secrets に `LEAGUE_ADMIN_TOKEN`（管理用、長いランダム文字列）と `LEAGUE_PREVIEW_CODE`（関係者用）を登録。
2. Actions →「league」→ Run workflow（ブランチ `owners-league`、deploy=`yes`）。※ 手動実行はワークフローが main にある必要があるため、ブランチを main に取り込むか、`league.yml` だけ先に main に入れる。
3. 出てきた `https://keiba-league.<サブドメイン>.workers.dev` を repository variable `LEAGUE_URL` に登録し、Pages を再ビルド。`/league/` は noindex・robots で除外・ナビ非表示のまま。
4. `/league/admin/` で管理トークンを入れ、節と対象レース（出走馬・適性・発走）を登録。

## 一般公開・賞品の前に確認すること

- 公開ゲームでの利用条件を満たすレース・結果データの経路（現状は管理者の手入力を想定。既存の取得経路を公開ゲームに使うことは未確認）。
- 大会規約（景品表示法の上限、賞品の受け取り・本人確認・不正の扱い、未成年の参加、個人情報）。
- 厩舎の引き継ぎはブラウザ保存のトークン方式。正式公開ではログイン方式（メールのワンタイムリンク等）を検討。
