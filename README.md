# keiba-ai

日本で開催される競馬（JRA・地方）の全レースをAI（Claude）が毎日分析し、外れも含めた全予想の回収率を記録するプロジェクト。

## 仕組み（予定）

1. **取得**（GitHub Actions・プログラム）：JRA公式サイトと楽天競馬から、出馬表・近走・オッズ・結果を取得し `data/` に保存
2. **分析**（Claude）：整形済みデータから評価点・印・買い目を作成し `predictions/` に保存
3. **集計**（プログラム）：全レース終了後に結果と照合し、回収率を `results/` に記録
4. **公開**：記事と成績表を静的サイトとして公開

## 取得の方針

- 各サイトの robots.txt とアクセス間隔の指定を守る（楽天競馬は60秒に1ページ、JRAは3秒に1ページ）
- 取得したデータは分析の材料にのみ使い、サイトには独自の印・評価・成績だけを掲載する

## 現在の段階

第1段階：`discover` ワークフローで実際のページを生HTMLのまま収集し、解析器を作る。
